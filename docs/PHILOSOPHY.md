# Design philosophy

Aporia draws from the organization of technical publications, records and instruments. The composition should make its most important information easy to find, verify and use.

| Principle | In practice |
| --- | --- |
| Archival discipline | Use stable headings, folios when useful, captions and explicit source context. Use material cues sparingly. |
| Hierarchy before decoration | Make the argument or task visible through position, weight, measure and alignment before introducing accent. |
| Red as annotation | Spend decorative red on one focal point. Use semantic red for states with a second cue. |
| Intentional density | Keep adjacent rows comparable and put relevant evidence near the decision. Plan landmarks and interruption points. |
| Evidence first | Prefer a runnable example, a labelled measurement or a recorded observation to a claim about quality. |
| Material restraint | Establish depth through paper and ink tones and boundaries. Use grain on appropriate publication surfaces only. |
| Structure as identity | Inspect in grayscale. Reading order, active state and primary action should survive. |
| Form governed by the task | Give a résumé a printable reading sequence, a tuner an immediate operating loop and a terminal a keyboard workflow. |

## Austerity and density

Austerity removes elements without a job. A dense matrix can express the identity clearly when row headers, column groups and units make comparison fast. Sparse spacing can obscure relationships when it pushes supporting evidence away from the claim.

## Editorial judgment

Start by naming the reader's question. Open with the answer or action and decide how much context the reader needs before the next decision. Add type, a border or a surface only where it clarifies a relationship. The reference artifacts document the decisions specific to their tasks.
