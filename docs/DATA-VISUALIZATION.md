# Data visualization

Use a table for exact lookup, a bar chart for magnitude, a line for time or sequence and a diagram for relationships or flow. Name each axis, unit, interval and sample size where applicable. Record the data source, baseline and any absent observations next to the figure.

Map series through `chart.*` and distinguish them with direct labels, solid fills, hatching, dots or an outlined marker where appropriate. Use focusable controls only when they reveal a useful value. Provide a table or text equivalent for essential information. Check the figure in grayscale and at the actual export size.

For architecture, show one relationship per diagram and name edges by what they carry. Keep quantitative claims and their measurement method adjacent. The [dossier](../references/editorial/dossier/) prints exact values beside its comparison, and the [proposal](../references/editorial/proposal/) keeps storage and protocol decisions visible together.
