# DDR-003 · Red as annotation

Accepted in 0.2.0 · 2026-11-28

## Context

A single chromatic emphasis makes the location of exceptions meaningful.

## Alternative

Using red as the primary control fill would put it in competition with diagnostics and focus.

## Decision

Keep decorative red to one anchor and use semantic red with contextual marks or words.

## Consequences

Primary controls invert the ground and foreground roles.
