# Anti-pattern catalogue

| Symptom | Cost | Aporia alternative |
| --- | --- | --- |
| Grid of equally prominent feature cards | Content with different importance looks interchangeable | Open with the main argument and give evidence a reading sequence |
| Oversized text above a sparse dashboard | Frequent tasks fall below the first screen | Use a bounded title, compact metrics and a focused table |
| Gradient, pill or shadow added to signal importance | Decoration competes with actual state | Use position, weight, ink contrast and one meaningful boundary |
| Red fill or color-only warning | Signal depends on color and dominates the task | Use a label, mark and semantic outline |
| Uppercase mono paragraphs | Tracking and uniform shapes impede reading | Use body type for sentences, mono for identifiers and code |
| Repeated decorative numerals | Navigation labels no longer identify real structure | Use folios for index, cross-reference or print context |
| Print styling imported into a TUI | Consumes cells and hides controls | Use literal operational labels, an active row marker and key hints |
| Staged editor illustration called a screenshot | Creates a misleading claim of runtime verification | Label the browser specimen and attach a provenance-bearing host capture |
| Generic product claims above unlabelled graphs | The reader cannot assess the outcome | State the measured change, baseline, units and method |

The [reference index](../references/) pairs each working artifact with an annotation naming the underlying decisions.
