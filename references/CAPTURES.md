# Reference captures

Each `screenshot.png` is a direct browser capture of its neighboring `index.html`. The viewport is 1280 × 900 CSS pixels at 1× scale, with local fonts, Chromium 158.0.8127.0, default fixture state and motion disabled during capture. These are screenshots of browser artifacts, including an explicitly simulated process review.

Reproduce from the repository root with `npm ci`, `npx playwright install chromium`, and `npm run capture:browser`. The command also refreshes the identity plate and browser gallery captures.
