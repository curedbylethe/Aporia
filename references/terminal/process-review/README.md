# Process review

[Open the working reference](index.html) · [Browser capture](screenshot.png)

Selection and focus have separate cues. Filtering updates the evidence and disables the action for an empty result. The confirmation shows the exact target and returns focus to its trigger. All actions use fixture data.

See the [capture provenance](../../CAPTURES.md) for viewport, browser and rendering method.

Run the native terminal demonstration with `python3 review.py` from this
directory. The same fixture records appear in the web simulation. Use a
terminal with a usable `TERM` and Python's curses module.

[Native Kitty capture](native.png) shows the same synthetic records in the
curses implementation with Lacuna Ink. It uses the Kitty version and native
capture environment documented in [capture provenance](../../../docs/screenshots/).
