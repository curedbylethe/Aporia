Decision record for a local-first desktop companion.

BOOX companion.

Start with recoverable file transfer and a read-only notes index. Add write-back after the device format and conflict semantics have been verified.

Architecture

BoundaryResponsibility
Device adapterEnumerate files and stage copies by device identity.
Local cataloguePersist hashes, index notes and record sync state in SQLite.
Desktop UIShow pending operations, conflicts and the next safe action.

Constraints

  • Work offline.
  • Preserve originals during sync.
  • Record firmware and file variants.
  • Avoid cloud dependencies for the first release.

Open question

Can edits preserve an unknown note's metadata? Round-trip fixtures across firmware versions before enabling write-back.

Dependency

SQLite supports atomic catalogue updates and local queries without a separate service. Keep device I/O outside its transaction and reconcile the staged files after a retry.

Alternative

A cloud relay would simplify discovery at the cost of offline use and an additional trust boundary.
