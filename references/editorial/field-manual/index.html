Device transfer procedure for a desktop operator.

Transfer a library.

Move a batch of books over a USB connection, then verify each destination before disconnecting.

ProcedureExceptions

Procedure

  1. Connect the reader and open its books directory.
  2. Copy files, preserving the source names in a transfer log.
  3. Compare file counts and open one destination file.
  4. Eject the device after the transfer completes.

Exceptions

ObservationResponse
Destination name existsCompare file size and hash before replacing it.
Connection lostReopen the device and verify the copied files against the log.
